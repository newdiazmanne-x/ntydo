NTYDO — Synthetic Intelligence & uv Quickstart

Free, cross-platform local-first workflow using uv (hatchling backend) and sandboxed execution across Termux (Android) and desktop systems.

Repository: github.com/newdiazmanne-x/ntydo

1. Termux (Android aarch64) — Copy & Run

Uses UV_LINK_MODE=copy and runs a zero-cost dry-run inside the isolated sandbox.

git clone https://github.com/newdiazmanne-x/ntydo.git && cd ntydo
export UV_LINK_MODE=copy
./scripts/nydo-sandbox.sh run uv run --link-mode=copy --project "$PWD/packages/si-agent" si-agent --goal "QR quickstart check" --tokens 512

2. Desktop (Linux / macOS / WSL) — Copy & Run

Clone, run the routing CLI (si-router), and execute unit tests via uv.

git clone https://github.com/newdiazmanne-x/ntydo.git && cd ntydo
export UV_LINK_MODE=copy
./scripts/uv-pipeline.sh si-router si-router -- --tokens 2048 --ranks 1
./scripts/uv-pipeline.sh si-router python -m unittest discover -s packages/si-router/tests -v

HITL & Security Baseline

  • Human-in-the-Loop (HITL): Review commands before running; multi-rank or cloud escalation paths require explicit approval.
  • Zero Secrets in Repo or QR: Keep credentials outside Git under ~/.secrets/ (chmod 600); never embed keys in URLs or pages.
