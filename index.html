INSTALL

Four commands. Same flow on phone and desktop — pick your shell, copy each line, run it in order.

01
pkg install -y git python uvTermux only — one pkg line gets git, python, and the prebuilt uv. Do NOT install uv with pip here: PyPI has no Android wheel, so pip tries a Rust source build and fails.
02
git clone https://github.com/newdiazmanne-x/ntydo.git
03
cd ntydo && UV_LINK_MODE=copy uv syncUV_LINK_MODE=copy — required on Termux storage, avoids hardlink failures.
04
./scripts/nist-release-check.shVerify — NIST-aligned release check, run bare: it takes no --json flag (only --verify-only). Expect 6/6 steps, 3 wheels, SHA-256 manifests verified.

README — THE SHORT VERSION

NTYDO is a public workspace for minimal cross-platform apps, Python utilities, and operational scripts. Clone it, sync it with uv, and it runs — on a phone in Termux or on a desktop, at zero cost.

  • Local-first. Execution happens on your machine. No hosted backend is required for Free.
  • One sync command. UV_LINK_MODE=copy uv sync sets up the Python package everywhere, including Termux.
  • Human in the loop. Nothing publishes or ships without explicit approval — run the check, read the result, then decide.

PUBLISH — APPLY THIS PAGE AS THE PATCH

This redesign is a single self-contained index.html — no build step, no extra files. Save this page's file over the repo's index.html, then paste these commands on Termux or desktop. Your git credentials never leave your device, and nothing goes live until you push.

01
cd ~/ntydo && cp index.html index.html.bakBack up the current page first — rollback stays one command away.
02
grep -n "pip install u[v]" index.html; grep -n "nist-release-check.sh --jso[n]" index.htmlAfter dropping in the new index.html, both greps must print NOTHING — proof the broken Termux line and the invalid --json flag are gone in this build. (The [v] / [n] keep each grep from matching its own line.)
03
./scripts/nist-release-check.shVerify before you publish — expect 6/6 steps, 3 wheels, SHA-256 manifests verified.
04
git add index.html && git commit -m "deploy: NTYDO Matrix sales redesign (whole-page patch)"
05
git push origin mainPush uses git's own stored credentials on your device — nothing is shared with anyone.
06
gh api repos/newdiazmanne-x/ntydo/pages -X POST -f source[branch]=main -f source[path]=/Turn on GitHub Pages. Needs gh auth login on your device first — or skip gh entirely: repo → Settings → Pages → Deploy from a branch → main → / (root) → Save.
Rollback any time: cp index.html.bak index.html or git revert HEAD. Human-in-the-loop: you approve, then you push.
