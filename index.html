README — THE SHORT VERSION

NTYDO is a public workspace for minimal cross-platform apps, Python utilities, and operational scripts. Clone it, sync it with uv, and it runs — on a phone in Termux or on a desktop, at zero cost.

  • Local-first. Execution happens on your machine. No hosted backend is required for Free.
  • One sync command. UV_LINK_MODE=copy uv sync sets up the Python package everywhere, including Termux.
  • Human in the loop. Nothing publishes or ships without explicit approval — run the check, read the JSON, then decide.

VERIFY — NIST CHECK

Before any release, run the NIST-aligned check and read its JSON output:

$
./scripts/nist-release-check.sh
  • 1Command exits clean and prints JSON — no silent failures.
  • 2Repo link points to github.com/newdiazmanne-x/ntydo and no other contact than the one in the footer appears.
  • 3Layout holds at desktop width and at a Termux / phone width — no broken panels or overflow.
  • 4Free vs Pro wording matches the repo. Get explicit approval before sharing or publishing anything.
