on hosting

      
Each specimen can live at its own path — /specimens/torus-knot/ — and this page just links out, keeping the index page light.

    

    

      
on gifs & video

      
This preview can't load remote images, so the loops above are live WebGL. On the real GitHub Pages repo, drop self-hosted .mp4/.webm loops (or Giphy embeds) straight into each card.

    

    

      
on structure

      
One index.html, one /specimens folder per sketch, three.js loaded from a CDN <script> tag — nothing to build or bundle.
